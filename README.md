# Mastering AI for Graduate Employability and Entrepreneurship

Proposal pages for universities, one folder per university, served on GitHub Pages.

- `kku/`: King Khalid University (Mastering AI for Graduate Employability and Entrepreneurship)
- `sme/`: small and medium businesses (Mastering AI for Business Results, The AI Shift × FLOW)
- `university/`: generic FLOW-branded university template (uses the `theme-flow` styles); copy it per appointment
- `assets/site.css`: shared styles, carried over from the KKU Demo Day report (saifai/kku-ai-hackathon-report)
- `assets/img/`: shared images

To add a university, copy `kku/index.html` into a new folder and change the page content. Anything still to confirm is wrapped in `<mark class="tbc">`, which shows as a yellow highlight.

The pages are not indexed by search engines (`noindex`) and the root page does not link to them.
